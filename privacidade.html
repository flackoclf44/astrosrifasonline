AVISO DE
PRIVACIDADE

Versão demonstrativa. Esta página não inclui cadastro, checkout, Pix ou envio de dados de participantes.

FUNCIONAMENTO

A seleção de números e o valor calculado existem somente enquanto você navega nesta página, em seu próprio navegador. Não existe backend desta demonstração para receber pedidos ou informações pessoais.

HOSPEDAGEM

O site é entregue por meio do GitHub Pages. O serviço de hospedagem pode tratar dados técnicos de acesso segundo suas próprias políticas. Para conhecer suas práticas, consulte a documentação e o aviso de privacidade do GitHub.

VERSÃO FUTURA

Antes de abrir uma campanha com pagamentos, o organizador deverá publicar aviso completo com identificação, contato, finalidades, tratamento de dados e formas de exercer os direitos aplicáveis.
